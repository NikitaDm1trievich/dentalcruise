# Промпт для разработки — лендинг «Дентал Круиз» (кодовая база)

Это техническое ТЗ для нового чата/сессии Claude Code, которая будет писать реальный код (в отличие от [claude-design-prompt.md](claude-design-prompt.md), который был для визуального макета в Claude Design). Скопируйте всё содержимое ниже одним куском в начале новой сессии.

## Контекст

Визуальный дизайн уже утверждён в Claude Design (файлы `*.dc.html`, `standalone-src.html`, `assets/`) — используем их **только как референс** вёрстки/цветов/анимаций, не как исходный код. Полная история решений — [site-brief.md](site-brief.md).

## Стек (согласовано, не пересматривать без явного запроса)

- **Фреймворк**: Astro (SSG, статическая сборка)
- **CSS**: Tailwind CSS
- **Контент**: Astro content collections — врачи, услуги, прайс-лист, кейсы "до/после", слайды карусели "О нас" хранятся как отдельные файлы данных (JSON), не хардкодятся в вёрстку. Добавление новой позиции = новая запись в файле.
- **Форма записи**: отправка через Cloudflare Worker (Hono), который безопасно пересылает заявку в Telegram-бота (токен бота — секрет Worker'а, не в клиентском коде)
- **Хостинг сейчас**: GitHub Pages (репозиторий `NikitaDm1trievich/dentalcruise`, ветка `main`), позже — переезд на существующий хостинг клиники (сейчас там Битрикс) — статическая сборка Astro переносится без изменений в коде
- **Анимации**: Anime.js для fade-in при скролле, морф бургер-иконки, кроссфейд карусели, поворот шеврона в аккордеоне
- **Hero**: видео пляжа (`assets/video/ocean-hero.mp4` из экспорта Claude Design) — сжать до 2-4 МБ, WebM+MP4, poster-заглушка, отключать автовоспроизведение на медленном соединении
- **Браузеры**: последние 2 версии Chrome/Safari/Яндекс.Браузера/Firefox, iOS 15+/Android 10+ — без легаси-костылей

## Структура сайта (5 страниц)

1. **Главная** — полностью спроектирована, см. блок ниже
2. **Прайс-лист** — заглушка/пункт меню, содержание проработаем отдельно
3. **О клинике** — заглушка/пункт меню
4. **Врачи** — заглушка/пункт меню
5. **Галерея работ** — заглушка/пункт меню, единая страница с фильтром по типу услуги (не отдельные страницы на каждую услугу)

Сейчас в разработку идёт **только Главная**, остальные — рабочие ссылки в навигации без содержимого.

## Блоки главной страницы (сверху вниз)

Полное описание каждого блока, палитры, шрифтов, анимаций — в [claude-design-prompt.md](claude-design-prompt.md) (раздел "Структура главной страницы"). Кратко:

1. Шапка: лого + Max/VK/телефон + бургер (без sticky bottom bar — её нет)
2. Hero: видео пляжа на весь экран, слоган белым текстом, без доп. элементов
3. "Почему мы" — сравнение с рынком
4. Топ-витрина услуг (3-4 карточки) → ссылка на страницу-галерею кейсов с фильтром
5. "О клинике" (тизер)
6. "Врачи" (тизер) — данные из `src/content/doctors/`
7. FAQ (аккордеон)
8. Отзывы (заглушка под виджет/ссылку на Яндекс Карты)
9. Трастовая полоса (лицензия + Яндекс Хорошее место + рейтинги)
11. Подвал, блок 1: кнопка записи + карточка места + иллюстрация Яндекс Карт
12. Подвал, блок 2: карта сайта + соцсети + копирайт + юр.реквизиты

## Палитра и шрифты

- Seashell `#EDE9E6`, Sea Glass `#C2CCC4`, Depths `#043041` — база/нейтралы/тёмный
- Яркий бирюзовый `#00B189` (в тон логотипу) — только для CTA-кнопок и акцентов
- Заголовки — жирный геометричный гротеск, капслок; текст — Manrope или аналог с кириллицей
- Только светлая тема, контраст на уровне WCAG AA как обязательный минимум

## SEO (без рекламных пикселей/колтрекинга — см. site-brief.md)

- `sitemap.xml`, семантичные мета-теги на каждой странице
- JSON-LD схема `LocalBusiness`/`Dentist` — реальные российские данные (адрес, +7-телефон, часы работы), НЕ австралийский шаблон
- Open Graph теги для превью ссылок в VK/Max/Telegram
- `robots.txt`

## Данные (структура content collections — предложение, можно уточнить в процессе)

```
src/content/
  doctors/          — один файл на врача: имя, специальность, стаж, фото, особенность (1-2 строки)
  services/         — виниры/коронки/протезирование: название, цена, фото результата
  price-list/        — полный прайс по категориям (для будущей страницы)
  cases/            — кейсы "до/после": фото до, фото после, категория услуги
  faq/              — вопрос-ответ
```
