# Правки после второй генерации — раунд 2 (уровень исполнения)

Референс по качеству ремесла (НЕ по контенту и НЕ по тону): https://www.smileandcompany.com/ — берём технику подачи (полноэкранные секции, анимации переходов, анимированное меню), не берём атмосферу "тёмный премиум-бутик" — наша аудитория (40-70 лет, средний класс) и позиционирование (доступность за счёт своей лаборатории) требуют света, воздуха и ясности, а не lux-минимализма без текста.

## Общий уровень исполнения — поднять по всей странице

Сейчас страница выглядит как набор отдельных "коробочек"-компонентов, собранных подряд. Нужно ощущение цельной, спроектированной страницы:

- Каждая секция — полноэкранная (full-bleed), фото внутри секций — на всю ширину/высоту блока, без белых полей вокруг картинки внутри карточки.
- При скролле каждая новая секция должна плавно проявляться (fade-in + лёгкое смещение снизу вверх на ~20-30px), а не просто быть статично видна сразу.
- Используй крупную типографику для заголовков секций, с небольшими eyebrow-подписями над заголовком в разрядку прописными буквами (например "СВОЯ ЛАБОРАТОРИЯ С 2013 ГОДА" уже есть в таком виде — сделай этот приём последовательным для всех секций, не только для одной).
- Больше "воздуха" (padding) вокруг секций — сейчас плотность выглядит любительской.

## Хедер и меню

- Гамбургер-меню должно анимироваться: иконка из трёх линий превращается в крестик при открытии (плавный переход, не мгновенная смена), а само меню выезжает/появляется с анимацией (slide или fade), а не просто мгновенно показывается.
- Верхняя панель (логотип + телефон/иконка + гамбургер) — при скролле может становиться компактнее/полупрозрачной с лёгким затемнением фона под ней, чтобы не спорить с фото ниже.

## Sticky bottom bar — изменить логику появления

- Не показывать нижнюю CTA-панель ("Позвонить / Прайс-лист / Как добраться") поверх самого первого экрана (hero) — пусть первый экран будет полностью свободен и "дышит".
- Панель плавно появляется (fade-in снизу) в момент, когда пользователь проскроллил мимо hero-секции, и дальше остаётся закреплённой до конца страницы.

## Hero — решено (кинематографичный + информативный)

- Полноэкранное фото (плейсхолдер "фото клиники/лаборатории") с лёгким эффектом медленного zoom (Ken Burns) — имитирует видео без реального видеофайла. Реальное видео — отдельная задача пользователя на будущее, сейчас не делаем.
- Поверх фото — логотип на верхнем слое, короткий явный заголовок про лабораторию (не абстрактный слоган), телефон/кнопка звонка видны сразу на этом экране, без прокрутки.

- FAQ — карточки с тенью, анимированный разворот шеврона при открытии
