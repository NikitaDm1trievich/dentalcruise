# Исходные логотипы

Официальные файлы, присланные клиникой. В сборку не попадают — это источник
для `src/components/core/BrandIcon.astro`, где пути вставлены инлайном
и перекрашиваются в `currentColor`.

| Файл | Что это |
|---|---|
| `vk-logo.svg` | Логотип ВКонтакте: синяя плитка + белый знак |
| `max-logo.svg` | Логотип Max: белый силуэт на прозрачном фоне |
| `logo-dentalcruise.svg` | Логотип клиники (рабочая копия — в `public/`) |

Если знак понадобится перерисовать, брать путь отсюда, а не из компонента.

## Значки сайта

Исходный знак — `public/favicon.svg`. Из него сделаны `public/favicon-96x96.png`
и `public/images/favicon.ico` с размерами 16×16, 32×32 и 48×48. Растровые варианты
имеют белый фон и отступ вокруг знака. `public/apple-touch-icon.png` (180×180)
сохранён. В HTML подключены ICO, PNG и значок Apple; SVG доступен по прежнему адресу.

## Награда Яндекс Карт

`public/images/yandex-good-place.webp` — значок «Хорошее место» из
[официальной страницы награды](https://yandex.ru/project/maps/goodplace/).
[Исходный PNG](https://avatars.mds.yandex.net/get-lpc/17800094/0ca48782-9005-4585-8ed9-ed5cbc57d5bd/width_1280_q100)
уменьшен до 176 px по ширине и сохранён в WebP для карточки отзывов.
Значок без года, изображение можно заменить или скрыть через CMS:
«Главная страница → Тексты блоков → 12. Отзывы → Значок «Хорошее место»».
