# Работы «до/после»

Страница «Галерея работ» (`/gallery`). Один JSON-файл на работу. Загрузчик
берёт только `*.json`, этот README игнорируется.

Работы добавляет владелец в редакторе: `/admin` → «Галерея работ (до и
после)» → «Создать». Редактор сам создаёт файл здесь (имя латиницей из типа
работы и времени: `veneers-20261001-143015.json`) и кладёт фото в
`public/images/cases/`.

```json
{
  "title": "Виниры E-max, верхний ряд",
  "category": "veneers",
  "before": "/images/cases/case-01-before.jpg",
  "after": "/images/cases/case-01-after.jpg",
  "note": "6 виниров, две недели от слепка до установки",
  "order": 10
}
```

- `category` — `veneers` / `crowns` / `implants` (выпадающий список «Тип
  работы» в редакторе). По нему работает фильтр; подписи кнопок — в
  `src/data/pages/gallery.json` (`filter`).
- Работа без одного из фото на сайт не выходит.
- Пока нет ни одной работы с обоими фото, страница показывает текст «идёт
  съёмка» (`empty` в `gallery.json`), закрыта от поисковиков (noindex) и не
  попадает в карту сайта (`astro.config.mjs`). Первая работа открывает её.
